# LightShade by DVision Software Group 1994

We made this demo for [Bizarre 1994](https://www.pouet.net/party.php?which=10&when=1994) in Nijmegen. We finished in 6th place.

## Instructions

Install [DOSBox Staging](https://www.dosbox-staging.org/).

Then run DOSBox with list.conf, something like

```bash
flatpak run io.github.dosbox-staging -conf lish.conf
```

or a similar command, depending on how DOSBox was installed.

In the config menu that follows, fill in these values:

| Prompt | Answer |
| --- | --- |
| Sound card | Gravis Ultrasound |
| Port | 240 |
| IRQ | 5 |
| DMA | 3 |

Enjoy!
